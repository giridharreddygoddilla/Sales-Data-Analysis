## 📌 Project Overview

This project uses Python to perform **exploratory data analysis (EDA)** on a sales dataset. It examines sales distributions, compares product categories and sub-categories, explores yearly sales across regions, and visualises monthly sales trends.

## 🎯 Key Objectives

- Analyse dataset structure, descriptive statistics, and missing values.
- Measure sales distribution using skewness and kurtosis.
- Compare total sales by product category and sub-category.
- Explore yearly sales performance across regions.
- Visualise sales distribution using a box plot.
- Identify monthly sales patterns through time-series visualisation.

## 🛠️ Technologies Used

- **Python** — Core programming
- **Pandas & NumPy** — Data handling and analysis
- **Matplotlib** — Data visualisation
- **SciPy** — Statistical analysis
- **Jupyter Notebook** — Interactive development

## 📈 Analysis and Visualisations

The notebook generates charts for:
- Total sales by category
- Total sales by sub-category
- Yearly sales by region
- Sales distribution and potential outliers
- Monthly sales trends

## 📂 Dataset

The project uses the [Sales Forecasting dataset on Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting/data).

## 🚀 Getting Started

Install the required libraries:

```bash
pip install pandas numpy matplotlib scipy jupyter
```

Download the dataset, update the CSV file path in the notebook, and run `Train_applied_datascience_1.ipynb` in Jupyter Notebook.

## 💡 Project Purpose

This project demonstrates practical data analysis and visualisation techniques for exploring historical sales performance. It provides a foundation for identifying trends and supporting further business analysis.

**Note:** The notebook focuses on exploratory analysis; it does not currently train a sales forecasting model.
